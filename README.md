# 基于 SpringBoot + Vue  的库房订单物流调度系统

用户下单端 · 商家运营端 · 平台管理后台 | 订单履约 · 智能调度 · 库存预警 · 效期管理 · 车辆调度

本项目是一套面向**多商家入驻 + 自营仓储 + 自有/外协车队调度**的综合性物流调度平台，采用前后端分离架构，覆盖**管理员（平台）、商家、终端用户**三类核心角色。系统围绕"用户下单→订单履约→库存扣减→车辆调度→物流配送→用户签收评价"的核心业务流程设计，同时集成采购管理、供应商管理、库存预警、保质期预警、车辆调度等模块，构建一体化的供应链协同与物流调度平台。

## 核心特性

- **智能订单履约（OMS）**：支持订单自动分仓、拆单/合单、库存预占、物流分配，用户下单后系统自动匹配最优发货仓库与物流方案，保障订单高效履约。
- **精细化库存管理（WMS）**：支持多仓库、多商家库存隔离管理，提供库存预警、保质期预警、FEFO（先到期先出）出库策略，有效降低库存损耗。
- **智能车辆调度（TMS）**：支持车辆档案管理、车次智能调度、路线规划、在途追踪，实现"人、车、货、路、单"最优匹配，降低空驶率与运输成本。
- **采购与供应链协同**：支持商家发起商品采购申请，管理员/商家管理供应商信息，采购订单跟踪与采购物流追踪，形成完整的供应链闭环。
- **多级预警体系**：库存低于安全阈值自动触发补货预警，商品临近保质期自动分级预警（黄色/橙色/红色），问题订单自动标记与异常检查。
- **商家会员与积分体系**：商家可升级为会员享受更低采购价与优先调度权，用户消费累积积分可兑换优惠券或商品，提升平台粘性。

## 功能模块概览

## 管理员端

管理员为平台运营中枢，负责全局管控与调度：

### 用户与商家管理

- **用户管理**：管理注册用户（终端消费者），包括用户ID、姓名、手机号、注册时间、账户状态、积分余额，支持用户信息查询与账户管理。
- **用户地址**：查看用户收货地址列表，包括地址ID、所属用户、省市区、详细地址、联系人、联系电话，支持地址审核与异常地址处理。
- **商家管理**：管理入驻商家，包括商家ID、商家名称、联系人、手机号、店铺状态、入驻时间、保证金、会员等级，支持商家审核、冻结/解冻、会员等级调整。
- **商家会员**：管理商家会员体系，包括会员等级、等级权益（采购折扣、优先调度、专属客服等）、升级条件，支持会员等级配置与调整。

### 商品与库存

- **商品管理**：管理全平台商品库，包括商品ID、商品名称、商品图片、商品类型、规格型号、售价、成本价、保质期天数、上下架状态，支持商品增删改查与批量导入。
- **商品类型**：管理商品分类字典，包括分类名称、父级分类、分类图标、排序，支持分类树形结构管理。
- **供应商管理**：管理供应商信息，包括供应商ID、供应商名称、联系人、联系电话、供应商品类、合作状态、信用评级，支持供应商增删改查与评级管理。
- **商品采购**：管理员发起采购订单，选择供应商、采购商品、数量、单价、期望到货时间，生成采购单，支持采购单状态跟踪。
- **采购记录**：查看全平台采购记录，包括采购单号、供应商、采购商品、数量、金额、采购状态（待发货/运输中/已到货）、采购时间，支持采购单详情查看。
- **采购物流**：跟踪采购订单的物流状态，包括物流单号、物流公司、当前位置、预计到货时间，支持物流轨迹查看与异常标记。
- **库存预警**：查看全平台库存预警商品，包括商品名称、当前库存、安全库存阈值、预警类型（缺货预警/积压预警），支持预警处理与补货建议。
- **保质期预警**：查看临近保质期的商品批次，包括商品名称、批次号、生产日期、到期日期、剩余天数、预警等级（黄色/橙色/红色），支持临期商品处理与FEFO出库策略配置。
- **商家库存**：查看各商家的库存情况，包括商家名称、商品名称、库存数量、库位信息、入库时间，支持库存查询与调拨。

### 订单与物流调度

- **订单管理**：查看全平台订单，包括订单号、下单用户、商品明细、订单金额、订单状态（待付款/待发货/运输中/已签收/已取消/已退款）、下单时间、物流信息，支持订单详情查看、手动改派、订单取消、退款处理。
- **车辆管理**：管理平台车辆档案，包括车牌号、车型、载重、容积、司机信息、车辆状态（空闲/在途/维修）、保险到期日、维修记录，支持车辆增删改查与状态管理。
- **车次调度**：根据订单配送需求进行车辆调度，包括调度单号、关联订单、分配车辆、司机、配送路线、发车时间、预计到达时间，支持智能调度推荐与手动调整。
- **问题检查**：查看异常订单与物流问题，包括问题类型（配送延误/货物破损/地址错误/客户拒收等）、关联订单、问题描述、处理状态，支持问题处理与责任追溯。

### 评价与数据

- **订单评价**：查看用户对订单/商品/物流服务的评价，包括评价内容、评分、评价图片、关联订单，支持评价审核与违规评价处理。
- **会员积分**：管理用户与商家的积分体系，包括积分规则（消费得积分/签到得积分）、积分兑换商品上架、积分流水查询，支持积分调整与兑换审核。
- **公告管理**：发布与管理平台公告，包括公告标题、内容、类型（系统通知/活动公告/政策更新）、发布时间、置顶状态，支持公告编辑与删除。
- **数据统计**：综合数据看板，展示核心运营指标（今日订单数/待发货数/本月营收/库存预警数/车辆利用率/商家入驻数），支持订单趋势、商家绩效对比、商品销量排行、物流时效分析、营收统计等多维度图表展示，支持报表导出。

## 商家端

商家通过独立运营端管理店铺与订单：

### 账户与店铺

- **商家注册登录**：支持商家账号注册与登录，提交入驻申请（商家名称、联系人、资质文件），管理员审核通过后开通店铺，支持找回密码。
- **密码修改**：修改登录密码，支持原密码验证。
- **商家信息**：查看与编辑店铺基本信息，包括店铺名称、店铺Logo、联系人、联系电话、店铺地址、经营品类，支持信息修改。

### 商品与库存

- **商品管理**：管理本店商品，包括商品名称、商品图片、商品类型、规格型号、售价、库存、保质期、上下架状态，支持商品增删改查与批量操作。
- **商家库存**：查看本店各商品的库存情况，包括商品名称、库存数量、库位信息、入库时间，支持库存盘点与库存调整。
- **库存预警**：查看本店库存预警商品，包括商品名称、当前库存、安全库存阈值，支持一键生成补货/采购申请。
- **保质期预警**：查看本店临近保质期的商品批次，包括商品名称、批次号、到期日期、剩余天数，支持临期商品促销处理与FEFO出库。

### 采购与供应链

- **商品采购**：向供应商发起采购申请，选择采购商品、数量、期望到货时间，生成采购单，支持采购单状态跟踪。
- **采购记录**：查看本店采购记录，包括采购单号、供应商、采购商品、数量、金额、采购状态，支持采购单详情查看。
- **采购物流**：跟踪本店采购订单的物流状态，包括物流单号、当前位置、预计到货时间，支持物流轨迹查看。

### 订单与调度

- **订单管理**：查看本店订单，包括订单号、下单用户、商品明细、订单金额、订单状态、下单时间，支持订单处理（确认订单/发货/退款）、物流信息录入。
- **订单评价**：查看用户对本店订单/商品的评价，包括评价内容、评分、评价图片，支持评价回复。
- **车辆管理**：管理本店自有车辆（如有），包括车牌号、车型、载重、司机信息、车辆状态，支持车辆增删改查。
- **车次调度**：对本店订单进行配送调度，分配车辆与司机，规划配送路线，支持调度记录查看。
- **问题检查**：查看本店订单的异常问题，包括问题类型、关联订单、问题描述、处理状态，支持问题处理。

### 会员与数据

- **商家会员**：查看本店会员等级与权益，包括当前等级、等级权益、升级进度，支持会员升级申请。
- **会员积分**：查看本店积分余额与积分流水，支持积分兑换商品。
- **积分物品兑换**：使用积分兑换平台商品或优惠券，查看兑换记录。
- **我的兑换记录**：查看本店历史兑换记录，包括兑换商品、消耗积分、兑换状态、兑换时间。

## 用户小程序端

用户通过小程序进行商品选购与订单管理：

### 账户与个人

- **账户注册登录**：支持手机号+验证码注册与登录，支持微信授权一键登录，支持找回密码。
- **密码修改**：修改登录密码，支持原密码验证。
- **个人信息**：查看与编辑个人基本信息，包括姓名、手机号、头像、性别，支持信息修改。
- **地址管理**：管理收货地址，包括新增/编辑/删除地址，设置默认地址，支持地址智能解析与定位。

### 购物与订单

- **选购下单**：浏览商品列表，按商品类型筛选，查看商品详情（图片、规格、价格、库存、保质期），加入购物车，选择收货地址后提交订单，支持在线支付（微信支付/支付宝）。
- **我的订单**：查看个人订单列表，包括全部/待付款/待发货/运输中/已完成/已取消订单，支持订单详情查看、物流轨迹追踪、取消订单、申请退款。
- **在线支付**：对订单进行在线支付，支持微信支付、支付宝，查看支付记录。
- **订单评价**：对已完成的订单进行评价，包括商品评分、物流服务评分、评价内容、评价图片，支持追加评价。
- **商品收藏**：收藏感兴趣的商品，查看收藏列表，支持取消收藏与降价提醒。

### 积分与通知

- **会员积分**：查看个人积分余额与积分获取记录，支持积分兑换优惠券或商品。
- **消息通知**：接收订单状态变更通知、物流更新通知、促销活动推送、积分变动通知等，支持消息列表查看与已读标记。
